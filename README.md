# Viatube

A responsive static website for saving video files that you own or have permission to download.

## Features
- Mobile-friendly dark glass UI
- Select and save a local video file without uploading it to a server
- Open a direct HTTP(S) video-file URL
- No account or backend required

## Important limitations
- Viatube does not download videos from Instagram, YouTube, TikTok, or other social-media pages.
- It does not remove watermarks, creator names, or attribution.
- A direct URL may open in a browser rather than download, depending on the host's settings.
- Only save content you own or have permission to download. Follow platform terms and copyright law.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub Pages will show your site URL after deployment.

This is a static front-end project. It does not require API keys, a server, or paid hosting.
